EN：

For editors who contributing to wikis where the visual editor has not been enabled or seeking for a better editor: I've developed this tool. It emulates certain features of existing visual editing tools and has been adapted to my own habits. You can use it to preview and get started with wiki editing more easily, and to begin with a near-native experience.

Features:

The line currently being edited displays its source code.

Templates and tags can be marked up using keyboard shortcuts.

Allows to edit tables in visible way.

Live preview.

Integrated AI functionality.

All currently known bugs in this tool have been fixed, but its functionality and long-term update support leave room for improvement. Thank you for your contributions to wiki knowledge in any form.

Puft, 8 October 2026, Beijing.
